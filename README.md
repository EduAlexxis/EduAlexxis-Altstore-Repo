# EduAlexxis AltStore Repository

This is the official AltStore, SideStore, and Scarlet source for ByeTunes and other iOS apps by EduAlexxis.

ByeTunes is an iOS app that lets you download and inject music and ringtones directly into your system library, completely bypassing iTunes sync.

---

## Direct Installation

To add this repository directly to your sideloading manager, visit the [repository website](https://edualexxis.github.io/EduAlexxis-Altstore-Repo/) and tap the installation buttons, or copy the URL below:

`https://raw.githubusercontent.com/EduAlexxis/EduAlexxis-Altstore-Repo/main/apps.json`

---

## Featured Apps

### ByeTunes
ByeTunes lets you download and inject music and ringtones directly into your iOS library. You don't need a computer for syncing.

- Inject music straight to your library.
- Background downloads with Lock Screen progress.
- Automatic metadata cleanup.
- Edit metadata and playlists inside the app.

---

## Repository Configuration

This repository includes several files that manage configurations:
*   `apps.json`: The repository index containing app metadata, screenshots, and version history.
*   `ServerStatus.json`: Controls the dynamic server status checks within the ByeTunes app (supporting active, maintenance, and dead states).
*   `supporters.json`: Lists the community supporters dynamically recognized in the app's settings screen.
